--------------------------------------------------------------------------------
The application is powered exclusively by a locally running Ollama server running 
on the user's local machine.

- AI Provider: Ollama
- Local Model: qwen3.5:4b (runs locally on device)
- Base URL: http://127.0.0.1:11434
- Native Endpoints:
  * GET  /api/tags    - Installed model discovery & capability verification
  * POST /api/chat    - Conversational inference, native multi-turn tool calling
  * POST /api/show    - Model metadata inspection
  * POST /api/embed   - Semantic embeddings for user memory
  * GET  /api/ps      - Active model memory status
- Zero Cloud API Keys: Strict zero-cloud policy. Never require OpenAI, Anthropic, 
  or external paid API keys.
- Backend Proxy: The frontend never connects directly to Ollama. All interactions 
  pass through the authenticated Express backend.

4. CORE APPLICATION MODULES & USER EXPERIENCES
--------------------------------------------------------------------------------
4.1 Today Execution Center (/today or /)
- Productivity Metric Strip: Displays Daily Consistency Score (0-100), deep work 
  hours logged vs. target, completed habits count, and pending tasks countdown.
- Quick-Capture Bar: Pressing Enter adds scheduled tasks or scratchpad todos 
  instantly without leaving the view.
- One-Click Habit Check-In Strip: Horizontal daily habit strip with immediate 
  check-in and fire streak counter (Flame icon).
- Priority-Grouped Tasks: Today's tasks categorized by priority (Urgent, High, 
  Medium, Low) with instant checkbox completion.
- Instant Focus Launcher: Start the global focus timer directly linked to any 
  scheduled task with one click.

4.2 My Goals & Curriculum Workspace (/goals, /goals/:id)
- 4-Level Curriculum Hierarchy:
  Folders -> Goals -> Milestones -> Modules
- Folder Organization: Nested folders (e.g. Computer Science, Career, Health). 
  Deleting a folder safely migrates goals to the root General folder without data loss.
- Dynamic Pacing Engine:
  Pacing Gap (%) = ((Elapsed Days / Total Days) * 100) - Achieved Progress (%)
  * Ahead: Progress exceeds elapsed timeline.
  * On Pace: Progress matches timeline within +/- 5%.
  * Mild Deficit: Progress lagging behind schedule (5% < Gap <= 15%).
  * Critical Deficit: Significant lag (Gap > 15%), triggering automated AI 
    rescheduling recommendations.
- Exact Module Generation: Generates an exact count of module slots (e.g. 30 slots 
  for a 30-day curriculum) and populates curriculum topics without duplicating records.
- Interactive Roadmap View: Expandable milestone accordions with real-time progress 
  bars, module checklists, and completion timestamps.

4.3 Task Management Engine (/tasks)
- Cadence Horizons:
  * Daily: Tasks scheduled for today or specific calendar dates.
  * Weekly: Broader deliverables meant to be completed within the current week.
  * Monthly: High-level milestones and deadlines.
- Priority Matrix: Color-coded badges for Urgent, High, Medium, and Low.
- Goal Attribution: Link tasks directly to active goals to automatically attribute 
  focus time and progress.
- Automated Overdue Detection: Identifies overdue tasks, displays days overdue, 
  and offers one-click rescheduling.
- Quick-Capture Todos (/todos): Scratchpad checklist for immediate thoughts; 
  converts into scheduled tasks with one click.

4.4 Habits & Adherence Matrix (/habits)
- 3 Dedicated Views:
  1. Full Month Adherence Grid (Default): Interactive 28 to 31-day matrix for any 
     selected month (?month=YYYY-MM). Sticky habit column on the left with horizontal cells.
  2. Week View: Focused 7-day strip emphasizing immediate momentum.
  3. Calendar View: Monthly card layout with density heatmaps.
- Streak Protection & Rest Days: Preserves active streaks on designated rest days 
  without penalizing the consistency score.
- Monthly Analytics:
  Adherence Rate = (Completed Check-ins / Scheduled Days) * 100
  Tracks active streak and longest all-time streak.

4.5 Global Focus Timer & Deep Work Sessions (/focus)
- Dual Operating Modes:
  * Pomodoro Mode: 25/50-minute structured study blocks followed by 5/10-minute rest breaks.
  * Stopwatch Mode: Open-ended flow state timer with precise millisecond tracking.
- Persistent Floating Dock: Remains visible across all pages without resetting the 
  timer when navigating the app.
- Session Attribution: Logs work duration directly against a specific Goal and Task 
  upon completion, feeding daily analytics.

4.6 Unified Calendar & Schedule Planner (/calendar)
- Views: Seamless switching between Day, Week, and Month layouts.
- Multi-Source Aggregation: Visualizes focus sessions, scheduled tasks, habit 
  check-ins, and milestone deadlines side by side.

4.7 Screen Time & Distraction Intelligence (/screen-time)

  * Distracting: Social media, video streaming, non-essential browsing.

  screen hours on goal velocity and daily consistency scores.

6. AUTONOMOUS LOCAL AI AGENT & TOOL EXECUTION ENGINE
--------------------------------------------------------------------------------
Accessible through both the dedicated /assistant page and the globally accessible 
floating voice drawer.

6.1 Agent Architecture & Workflow:
1. Multilingual Bidirectional Interaction: Full natural speech and text support in 
   English, Hindi, and Hinglish.
2. Instant Intent Interceptors: Affirmative confirmations ("yes", "confirm", "haan 
   proceed karo") and undo commands ("undo", "undo that", "undo karo") execute 
   immediately with zero LLM inference delay.
3. Domain-Aware Tool Slicing: Dynamically provides only relevant tool definitions 
   based on user query intent, preventing context bloat and keeping response 
   latencies under ~45ms.
4. Selective Thinking: Enables reasoning chains only for complex planning queries 
   (e.g., "Create a 60-day syllabus for Java"), keeping routine commands fast.
5. Interactive Action Cards: Responses render rich UI cards (ActionCard.tsx) with 
   direct entity navigation and instant undo controls.
6. Instant Undo & Snapshots: Every mutation creates a snapshot in AssistantToolExecution. 
   The user can click Undo on any card or say "undo" to revert the change immediately.
7. High-Risk Confirmation Protocol: Permanent deletions generate a cryptographic 
   confirmation token (5-minute TTL). Deletions only proceed after an explicit 
   affirmation ("yes", "confirm", "haan" or button click).
8. Real-Time UI Updates: Mutations trigger TanStack Query cache invalidations 
   (['tasks'], ['goals'], ['habits'], ['analytics']), updating every open page 
   instantly without manual reload.

7. MATHEMATICAL FORMULATIONS & MACHINE LEARNING
--------------------------------------------------------------------------------
7.1 Daily Consistency Score Formula:
Score = w_h * (H_c / H_t) + w_t * (T_c / T_t) + w_f * min(1, F_m / F_target) - P_distraction

Where:
- H_c / H_t: Habits completed over scheduled habits (w_h = 40%)
- T_c / T_t: Tasks completed over scheduled tasks (w_t = 30%)
- F_m / F_target: Focus minutes logged over daily target (w_f = 30%)
- P_distraction: Screen distraction penalty (deducts points when distracting screen 
  time exceeds 2 hours)

7.2 Python ML Service Algorithms:
- Isolation Forest: Detects unusual behavioral slumps in daily focus and consistency scores.
- Pearson & Spearman Correlation: Computes relationships between distracting screen 
  hours and task completion velocity.
- Apriori Algorithm: Discovers habit stacking patterns (e.g. "Completing LeetCode 
  in the morning increases 2L Water habit adherence by 82%").
- K-Means Clustering: Groups work sessions into distinct energy clusters (High Flow, 
  Moderate Focus, Fragmented).
